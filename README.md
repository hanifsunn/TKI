Proyek ini bertujuan untuk memahami cara kerja serta mengukur efektivitas dari dua algoritma stemming yang berbeda yakni:
TALA Stemmer, yang dirancang khusus untuk Bahasa Indonesia,
Lovins Stemmer, salah satu stemmer tertua untuk Bahasa Inggris. 
Melalui eksperimen ini, penulis menerapkan kedua stemmer pada kumpulan dokumen nyata, lalu mengevaluasinya menggunakan tiga metrik utama, yaitu: 
Under-stemming Index (UI), 
Over-stemming Index (OI), 
Mean Words per Conflation Class (MWC).
